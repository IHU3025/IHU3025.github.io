Part 1.1: Convolutions from Scratch

I implemented convolution with four nested loops (Two nested loops iterate over each pixel (x, y) in the output image to assign its value, while another pair of nested loops traverse every pixel in the filter to compute the average color for the output pixel) and then optimized the inner two loops to element-wise multiplication:


process = padded_image[i:i+filter_h, j:j+filter_w]
output[i, j] = np.sum(process * filter)

Implementation Details:

  • Four-loop implementation: implementation with four nested loops for image height, width, and kernel height, width
  • Two-loop optimization: Used numpy element-wise multiplication operations to simplify the inner two loops
  • Padding: Implemented zero-padding using numpy: np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant', constant_values=0) with pad_h = filter_h//2 and pad_w = filter_w//2
  • Comparison with scipy: My implementation produces identical results to scipy.signal.convolve2d but is significantly slower due to python loops

Part 1.3: Derivative of Gaussian (DoG) Filter

By appling Gaussian smoothing before computing derivatives (DoG filter), the noise in the binarized edge image is significantly reduced.

Edges with and without Gaussian blur (threshold = 20)
Two Step Result vs. One Convolution Result (threshold = 50)

Implementation Details:

  • Two step Derivative of Gaussian Filter: Created using cv2.getGaussianKernel() with outer product to create the gaussian filter, applying the filter to the image first then convolve the blurred image with the finite difference operator:


    • gaussian = gaussian_filter(sigma=1.5, size=9)
    blurred = convolve2d(img, gaussian, mode='same')
    Ix_two_step = convolve2d(blurred, Dx, mode='same')
    Iy_two_step = convolve2d(blurred, Dy, mode='same')
    edges_two_step = np.sqrt(Ix_two_step**2 + Iy_two_step**2) > 50


  • DoG filter: Since convolution is associative, we can acheive the same result by convolved Gaussian kernel with finite difference operators to get the DoG Kernel:

    • DoG_x = convolve2d(gaussian, Dx, mode='full')
    DoG_y = convolve2d(gaussian, Dy, mode='full')

Part 2.1: Image "Sharpening"

Implemented unsharp masking to enhance image details by amplifying high-frequency components.

Implementation Details:

  • Sharpening: implemented gaussian_filtered function to blur the image. Then, the high_freq function obtain the high frequency by subracting the blurred from the original image. After that the sharpening_filter function added high frequency by sharpened = img + alpha * high_freq(img) and clip the sharpened image ensuring values are within the range of 0 to 255
  • Evaluation results: This method does effectively made sharp image even sharper
  • Unsharp masking: Since convlution is associative: I = I + α * (I - I_blurred)

    • gaus_filter = gaussian_filter(sigma=1.5, size = 16)
    identity = np.zeros((size, size))
    center = size // 2
    identity[center, center] = 1.0
    # img + alpha * (img - gaus) = (1 + alpha) * img - alpha * gaus
    unsharp_filter = (1 + alpha) * identity - alpha * gaus_filter

Part 2.3: Gaussian and Laplacian Stacks

Constructed the Gaussian stack by successively applying Gaussian filtering at each level. The Laplacian stack was then generated by subtracting each level of the Gaussian stack from the next, capturing the frequency differences between each Gaussaian level.

PS: Laplacian Level 4 is same image as the Gaussian level 4, I clipped the Laplacian stack for better display, so the color looks different.

Implementation Details:

  • Gaussaian Construction: implemented gaussian_stack() function to successive apply Gaussian filters with increasing sigma values
    • Sigma multiplier increases the blur radius at each subsequent level
    • Kernel size is calculated as 2 * ceil(3 * sigma) + 1 for coverage
  • Laplacian Construction: Each Laplacian level = Gaussiani - Gaussiani+1, with the last level of the Laplacian stack contains the final Gaussian level.

    • for i in range(len(gaussian_stack_list) - 1):
    lap_level = gaussian_stack_list[i] - gaussian_stack_list[i + 1]
    laplacian_stack_list.append(lap_level)
