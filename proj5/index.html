This project explores diffusion models for image generation and editing using the DeepFloyd IF model. The implementation includes forward diffusion processes, iterative denoising, classifier-free guidance, and applications such as image-to-image translation, inpainting, visual anagrams, and hybrid image generation.

1.1 Forward Function Implementation

\[ q(x_t \mid x_0) = \mathcal{N}\!\big(x_t;\; \sqrt{\bar{\alpha}_t}\,x_0,\; (1-\bar{\alpha}_t)\,I\big) \]

def forward(im, t):
    alpha_bar_t = alphas_cumprod[t]
    epsilon = torch.randn_like(im)
    im_noisy = torch.sqrt(alpha_bar_t) * im + torch.sqrt(1-alpha_bar_t) * epsilon
    return im_noisy

1.4 Iterative Denoising

\[ x_{t'} = \frac{\sqrt{\bar{\alpha}_{t'}} \, \beta_t}{1 - \bar{\alpha}_t} \, x_0 + \frac{\sqrt{\alpha_t}(1 - \bar{\alpha}_{t'})}{1 - \bar{\alpha}_t} \, x_t + v_{\sigma} \]

where:

  • x_t is the noisy image at timestep t.
  • x_{t'} is the less noisy image at the next timestep.
  • x_0 is the current estimate of the clean image (one-step denoising).
  • \bar{\alpha}_t comes from alphas_cumprod.
  • v_{\sigma} adds variance for stochasticity.

1.6 Classifier-Free Guidance (CFG) Denoising

Combines a conditional noise estimate (based on a text prompt) and an unconditional noise estimate (based on an empty prompt)

The CFG noise estimate is defined as:

\[ \epsilon = \epsilon_u + \gamma \, (\epsilon_c - \epsilon_u) \quad \]
  • ε_c: noise estimate conditioned on the text prompt.
  • ε_u: unconditional noise estimate (empty prompt).
  • γ: guidance scale.
    • γ = 0 → unconditional estimate
    • γ = 1 → conditional estimate
    • γ > 1 → higher quality images (less diversity)
# Run UNet twice to get cond_output and uncond_output

1.7.2 inpainting

At each step of the diffusion denoising loop, after obtaining x_t, we enforce the constraint:

\[ x_t \;\leftarrow\; \mathbf{m} \, x_t \;+\; (1 - \mathbf{m}) \, \text{forward}(x_{orig}, t) \ \]
  • x_t: the current noisy image at timestep t.
  • x_orig: the original image before editing.
  • m: binary mask (1 = region to edit, 0 = region to preserve).
  • forward(x_orig, t): the forward process that adds the correct amount of noise to the original image at timestep t.

1.8 Visual Anagrams

At each step we compute two noise estimates: one conditioned on prompt p₁ using the original image xₜ, and one conditioned on prompt p₂ using the vertically flipped image flip(xₜ). Then we flip the second estimate back, and average the two noises.

\[ \epsilon_1 = \text{CFG of UNet}(x_t, t, p_1) \ \] \[ \epsilon_2 = \text{flip}(\text{CFG of UNet}(\text{flip}(x_t), t, p_2))\ \] \[ \epsilon = (\epsilon_1 + \epsilon_2) / 2 \ \]

1.9 Hybrid Images

At each step we compute two noise estimates: one conditioned on prompt p₁ using image xₜ, and one conditioned on prompt p₂ using image xₜ. Then combine the two noises by low-pass filtering the first and high-pass filtering the second.

\[ \epsilon_1 = \text{CFG of UNet}(x_t, t, p_1) \ \] \[ \epsilon_2 = \text{CFG of UNet}(x_t, t, p_2)\ \] \[ \epsilon = f_\text{lowpass}(\epsilon_1) + f_\text{highpass}(\epsilon_2)\ \]

This happen because with MSE loss, the model learns to predict the point minimizing squared distance to all outputs. Since inputs are pure noise the optimal prediction will minimizes average squared error across all training images resulting a "averaged digit" across pixels.

2.2 Training the UNet

To train the time-conditioned UNet \( v_\theta(x_t, t) \) to predict the flow \( u(x_t, t) = x_1 - x_0 \), for each batch:

  1. Sample a clean digit \( x_1 \) from the MNIST training set.
  2. Sample a timestep \( t \sim \mathcal{U}(0, 1) \).
  3. Sample a noise image \( x_0 \sim \mathcal{N}(0, I) \) with the same shape.
  4. Construct the interpolated sample \( x_t = (1-t)\,x_0 + t\,x_1 \).
  5. Compute the target flow \( u = x_1 - x_0 \) and minimize the MSE loss between \( u_\theta(x_t, t) \) and \(u \).

Training setup:

  • Dataset: MNIST training set via torchvision.datasets.MNIST.
  • Batch size: 64.
  • UNet hidden dimension: \(D = 64\).
  • Optimizer: Adam, learning rate \(1 \times 10^{-2}\).
  • Scheduler: ExponentialLR with gamma = \(0.1^{(1.0 / \text{num_epochs})}\), stepped once per epoch.
UNet training loss curve

2.3 Sampling from the UNet

For sampling, we used learned flow field to iteratively derive the pure noise samples toward the MNIST data manifold. We discretize the interval \([0, 1]\) into \(N\) equal steps and perform forward Euler updates:

\[ x_{t_{k+1}} = x_{t_k} - (t_k - t_{k+1}) \, v_\theta(x_{t_k}, t_k). \]

2.4 Adding Class-Conditioning to UNet

To gain finer control over generation and improve sample quality, we add class conditioning to UNet on digit labels. The class label is encoded as a one-hot vector and passed through FCBlocks in parallel with the time embedding.

classifier-free guidance randomly drop the class conditioning with probability \(p_{\text{uncond}} = 0.1\), replacing the one-hot vector with zeros:

2.6 Sampling from the UNet

At sampling time, we fix a target digit class \( c \) and use classifier-free guidance with guidance strength \( \gamma = 5.0 \). And generate both conditional and “dropped” (unconditional) predictions from the UNet, then combine them:

\[ u(x_t, t, c) = u_{\text{uncond}}(x_t, t, 0) + \gamma \big( u_{\text{cond}}(x_t, t, c) - u_{\text{uncond}}(x_t, t, 0) \big). \]
