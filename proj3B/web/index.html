PART A: Image Mosaicing Project Overview

This project explores image mosaicing by computing homographies between overlapping images, warping them into alignment, and blending to create seamless panoramas. All homography computation and image warping is implemented from scratch without using high-level computer vision libraries.

A.2: Recovering Homographies

Homography Computation Implementation

I implemented homography computation using Direct Linear Transform. The homography matrix H transforms points from one image to another: p' = Hp, where p and p' are corresponding homogeneous points.

Mathematical Formulation

The homography transformation is represented as:

$$ \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} = \begin{bmatrix} h_1 & h_2 & h_3 \\ h_4 & h_5 & h_6 \\ h_7 & h_8 & 1 \end{bmatrix} \begin{bmatrix} x \\ y \\ 1 \end{bmatrix} $$

We can rewrite the matrix equation into a system of equations:

    \begin{align*} u &= \frac{h_1 x + h_2 y + h_3}{h_7 x + h_8 y + 1} \\ \\ v &= \frac{h_4 x + h_5 y + h_6}{h_7 x + h_8 y + 1} \end{align*}

Rearranging the previous equations we get:

    \begin{align*} h_1 x + h_2 y + h_3 - h_7 x u - h_8 y u &= u \\ \\ h_4 x + h_5 y + h_6 - h_7 x v - h_8 y v &= v \end{align*}

ComputeH function Implementation Steps

  • Initialize matrix for the linear system, with A being the coefficient matrix with the shape of 2nx8 for n point pairs, and b being the target value (u, v)
  • Construct the system of equations:
    For each point correspondence, two equations are added (one for the x-coordinate and one for the y-coordinate):
    A.append([x, y, 1, 0, 0, 0, -xp*x, -xp*y])
    b.append(xp)
    A.append([0, 0, 0, x, y, 1, -yp*x, -yp*y])
    b.append(yp)
    This builds a system with the form A · h = b, where h has the 8 unknown parameters we want to solve.
  • Convert lists to numpy arrays and solve the linear system:
    If the system is square, solve it with h = np.linalg.solve(A, b)
    Otherwise use least squares to find the best approximate solution: h = np.linalg.lstsq(A, b, rcond=None)[0]

    A.3: Warping Images

    Inverse Warping Implementation

    Implemented both nearest neighbor and bilinear interpolation from scratch using inverse warping to avoid holes in the output image.

    The warpImage(im, H, interp_func) function performs inverse warping using a homography matrix H and an interpolation method interp_func. It computes the output bounds by calling the get_output_size function (which transforming the corners of the input image and find bounding box from the transformed corners) then maps each output pixel back to the source image using H-1.

    Alpha Channel and Bounds Management

    I used a mask to deal with output pixels that don't map to any input pixels:

    mask = (x_src >= 0) & (x_src <= w_src-1) & (y_src >= 0) & (y_src <= h_src-1)

    Through this check, pixels outside the source image bounds are marked transparent in the alpha channel, and will not be displayed.

    Interpolation Methods

    Nearest Neighbor Interpolation

    The nearest_neighbor_interp(im, x, y) function rounds the input coordinates to the nearest integer pixel and returned the rounded pixel's value.


    Bilinear Interpolation

    The bilinear_interp(im, x, y) computes a weighted average of four neighboring pixels.

    \[ I(x, y) = (1 - dx)(1 - dy) \cdot I_{00} + dx(1 - dy) \cdot I_{10} + (1 - dx)dy \cdot I_{01} + dx \cdot dy \cdot I_{11} \]

    Theoretically produces smoother results than Nearest Neighbor approach but is computationally more expensive.

    A.4: Blending Images into Mosaic

    Mosaic Construction Overview

    This implementation constructs a mosaic from two images by:

    1. Aligning the second image to the first using a homography
    2. Building smooth, distance-based blending masks for overlapping regions
    3. Combining the two images using weighted averaging according to those masks
    4. Automatically cropping the final mosaic to remove empty borders

    The blending function uses Euclidean distance transforms to result smooth weights that favor pixels closer to the interior of each image region/ farther from the edge.

    Functions Implementation

    The create_blending_mask(warped_img, reference_img) function produce a per pixel blending weight alpha_mask the two aligned images. The weight for reference_img is 1 - alpha_mask.

    • Binary Masks: create mask_warped and mask_reference which are binary masks indicating which pixels contain valid image content (by checking if the pixel is none zero).
    • Distance Transforms: dist_warped and dist_reference are computed using ndimage.distance_transform_edt. It return the distance to the nearest background pixel for each valid pixel.
    • Alpha Calculation: For overlapping pixels, calculate the alpha by alpha = dist_warped / (dist_warped + dist_reference) which gives pixel weight correspond to their distance.
    • Pixels only belong to warped_img have alpha = 1.0. Pixels only belong to reference_img have alpha = 0.

    The blend_images_weighted(img1, img2, alpha_mask) function blend two aligned RGB images into one using the alpha mask:
    blended = img1 * alpha + img2 * (1 - alpha)

    The compose_mosaic_distance_blend(img1, img2, H, interp_func) warp img2 into img1’s coordinate frame using homography H, get weights and blend accordingly, then crop the result.

    • Compute Bounding Box: Calculate the corners of img1 and the transformed corners of img2 using H. Stack and compute min_x, min_y, max_x, max_y to define the mosaic canvas size.
    • Construct translation matrix:
      T = [[1, 0, -min_x], [0, 1, -min_y], [0, 0, 1]]
      Then adjust the homography so the transformed image land in the canvas:
      H_adjusted = T @ H
    • Warp img2: Use warpImage(img2, H_adjusted, interp_func) to warp warped_img2 on the canvas.
    • Add img1: Initialize a zero canvas of shape (mosaic_height, mosaic_width, 3). Paste img1 into its canvas position using offset (-min_x, -min_y).
    • Create Blending Mask and Blend the Overlapping Region:
      • Call create_blending_mask(warped_rgb, canvas_region) to compute alpha_mask.
      • Call blend_images_weighted(warped_rgb, canvas_region, alpha_mask) to compute blended_region.
      • Write blended_region back into the canvas.
    • Auto-Crop Final Mosaic:
      • Compute non_empty_mask where any color channel is non-zero.
      • Determine minimal bounding rows/columns with content.
      • Add padding and clip to canvas boundaries. Then crop canvas to these bounds and return the final mosaic.

    PART B: Feature-Based Automatic Image Stitching Project Overview

    This part of project implements a complete automatic image stitching pipeline based on the paper "Multi-Image Matching using Multi-Scale Oriented Patches". The pipeline first detects Harris corners, extracts feature descriptors, matches features between images, then uses RANSAC to compute homographies.

    B.1: Harris Corner Detection

    Harris Corner Detector

    Used the the given get_harris_corners function in the harris.py file to identify interest points in images. The algorithm computes corner response using the matrix and eigenvalues.

    Algorithm Logic

    1. Apply Gaussian Smoothing: for noise reduction and more consistent result
    2. Compute image gradients: Calculate Ix and Iy using Sobel filters
    3. Compute products of gradients: Ix², Iy², IxIy
    4. Apply Gaussian smoothing: Compute weighted sums over a window
    5. Compute corner response: R = det(M)/trace(M) with M being the matix:
      6. M = [ ∑ window I x 2 ∑ window I x I y ∑ window I x I y ∑ window I y 2 ]
    6. Threshold response: Select points with R > threshold

    Adaptive Non-Maximal Suppression (ANMS)

    Implemented ANMS to select spatially well-distributed corners by suppressing weaker corners near stronger ones, ensuring better feature distribution across the image while preserving the most prominent corners.

    ANMS Algorithm

    The anms(h_value, coord, num_points, c_robust=0.4) gets the h_value, and detected points from the harris corner function. It return the best num_points points and their corresponding radius (the radius where they are the local best point).

    1. For each corner, find all other corners that have a Harris response value strong enough to suppress it.
      2. for i in range(n):
         # Find corners that are significantly stronger
         stronger_pts = h_value > (h_value[i] / c_robust)
    2. Calculate Suppression Radius: find the minimum distance from the current point to any significantly stronger corner
      • If stronger corners exist → find the closest distance to them
      • If no stronger corners exist → this corner is a local maximum (radius = ∞)
    3. Sort corners by suppression radius in descending order
    4. Select the top N corners with largest suppression radii

    B.2: Feature Descriptor Extraction

    Feature Descriptor Implementation

    Extracted 8×8 feature descriptors from 40×40 patches around each interest point, with the pixel value normalized.

    Descriptor Extraction Steps

    1. Extract 40×40 patch centered at each interest point
    2. Downsample the patch to 8×8 by skipping pixels at regular intervals.
    3. Apply bias/gain normalization:
      # normalized = (patch - mean) / std
      patch = (patch - np.mean(patch)) / (np.std(patch) + 1e-8)
    4. Flatten to 64-dimensional feature vector

    B.3: Feature Matching

    Feature Matching Implementation

    Implemented feature matching using Lowe's ratio test to find reliable correspondences between images.

    Matching Algorithm

    The feature_matching(descriptors_1, valid_coords_1, descriptors_2, valid_coords_2, threshold=0.8) returns the matched descriptors and coordinates in paired order.

    1. For each descriptor in image 1, find two nearest neighbors in image 2:
      nbrs = NearestNeighbors(n_neighbors=2).fit(descriptors_2)
      distances, indices = nbrs.kneighbors(descriptors_1)
    2. Compute distance ratio: d₁/d₂
    3. Apply threshold (default 0.8) to accept matches
    4. Keep matches where ratio < threshold

    B.4: RANSAC for Robust Homography

    RANSAC Implementation

    Implemented 4-point RANSAC to compute robust homography estimates from potentially noisy feature matches and handle outliers.

    RANSAC Algorithm

    The ransac_corrected(src_pts, dst_pts, num_iter=1000, inlier_threshold=10) function returns the best_H (best homography matrix), best_inlier (maximum number of inliers found), best_error (minimum average reprojection error), best_inlier_mask ( boolean mask of inlier point)

    1. Randomly select 4 feature correspondences: select minimal sample set for homography estimation to avoid outlier
      2. if src_pts_xy.shape[0] >= 4:
         idx = np.random.choice(src_pts_xy.shape[0], 4, replace=False)
      else:
         idx = np.arange(src_pts_xy.shape[0])
    2. Compute homography H using the 4 points by calling the computeH function
    3. Project all points from image 1 to image 2 using src_transformed = apply_homography(src_pts_xy, H)
    4. Count inliers: count points with error (Euclidean distance between projected and actual points) within distance threshold
    5. Update model: if (num_inliers > best_inlier) or (num_inliers == best_inlier and avg_error < best_error) we update the best inlier and error to the current correspondence's data
    6. Repeat for N iterations, keep homography with most inliers
    7. Recompute homography using all inliers
